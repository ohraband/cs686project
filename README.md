Reinforcement Learning as an Alternative to Simulated Annealing for MaxSAT \
\
Mostly out of curiosity.
# Minimal setup

1. Make sure the problemset folder is in the same directory as the .py file
2. Specify the folder name in the .py file's main section
3. Run


## Problemsets
The problems are originally for weighted maxsat, so the clauses include weights and solutions for the weighted instances are in the weights_solutions folder.
